Crea manga sin saber dibujar

YUSEPE manga es una herramienta de escritorio gratuita que te permite maquetar, componer y gestionar todas las páginas de tu manga — escribí tu historia, componé viñetas, añadí personajes y globos de diálogo, generá fondos con IA y prepará tu obra para imprimir. Sin formación en dibujo. Sin fricción.

Descargar Ver más

Todo lo que necesitás para tu manga

Desde la primera viñeta hasta el capítulo final, sin salir de la app.

▦

Viñetas poligonales

Dibujá viñetas arrastrando, dividilas en columnas o deformá sus esquinas libremente. Guardarraíl convexo. Clip automático del contenido.

💬

Globos de diálogo

4 tipos (diálogo, pensamiento, grito, cartela), cola orientable, 9 fuentes japonesas, sombra configurable y marcos para cartelas.

✨

Fondos con IA

Generá fondos para tus viñetas con Pollinations.ai. 27 estilos, 3 variantes por prompt. Biblioteca reutilizable.

✏️

Dibujo a mano alzada

Pluma con 3 tintas × 3 grosores, borrador, y 8 timbres de trama (screentone) con tamaño ajustable por slider.

👤

Constructor de personajes

Cara, ojos, expresión, cabello y piel paramétricos. Guardalos con nombre y colocalos en tus viñetas.

📖

Constructor de historia

Premisa, capítulos y escenas vinculadas a páginas. Estructurá toda la trama dentro de la misma app.

Stack moderno

Electron 33 React 18 TypeScript Tailwind CSS v4 electron-vite SVG Pollinations.ai Google Fonts

Instalación

Cloná el repo, instalá dependencias y ejecutá en modo desarrollo.

git clone https://github.com/jmjauregui/YUSEPE-manga.git

cd YUSEPE-manga

# Node 20 obligatorio

nvm use 20

npm install

npm run dev

Generación de fondos con IA: creá un archivo .env con APIKEY_pollinations = tu_key para habilitar la integración con Pollinations.ai.
