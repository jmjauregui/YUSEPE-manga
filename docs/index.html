Editor de páginas

Viñetas deformables, globos de diálogo SVG, onomatopeyas, timbres de screentone, imágenes y dibujo a mano alzada.

Fondos con inteligencia artificial

27 estilos combinables, 3 imágenes por generación, biblioteca reutilizable.

Constructor de historia

Premisa, capítulos y escenas vinculadas a páginas del manga.

Biblioteca de contenido IA

Creando una portada para manga

Características

Una fábrica de manga completa

▦

Viñetas poligonales

Dibujo por marquee, división con gutter automático, clip poligonal y modo deformar con 4 vértices libres.

💬

Globos de diálogo

4 tipos SVG, cola orientable, 9 fuentes, sombra configurable y estilos de marco para cartelas.

✨

IA integrada

Pollinations.ai para fondos generativos. 27 estilos, semillas múltiples y biblioteca reutilizable.

✏️

Dibujo y screentones

Pluma vectorial 3×3, borrador, 8 timbres de trama con slider de tamaño continuo.

💥

Onomatopeyas

Texto SFX con 3 estilos, rotación, 3 colores y selector de fuente.

👤

Personajes

Constructor paramétrico: cara, ojos, expresión, cabello. Guardado con nombre.

📖

Historia

Premisa, capítulos y escenas con vínculo a páginas. Todo sincronizado.

💾

Guardado automático

Nunca perdés trabajo. Autosave cada 600 ms. Formato .ymanga portable.

Instalación en 3 comandos

Terminal

git clone https://github.com/jmjauregui/YUSEPE-manga.git

cd YUSEPE-manga

# Requiere Node 20

nvm use 20

npm install

npm run dev

# Abrí la app y empezá tu manga ✨

🤖 Fondos con IA: creá un archivo .env con
APIKEY_pollinations = tu_api_key
